Star Map Navigation

About Project
This project was created as a display of different methods of pathfinding algorithms. Connecting different nodes or "stars" with routes and calucating efficient paths to a target location.
Project Details
  • Unity Engine
  • Pathfinding
  • C#
  • Djkstra
Pathfinding
This project has the option of finding a path using Djkstra, Greedy or A* algorithms. Before the user selects the target start and end points, the manager calculates the distance between each node with a valid route and adds the node class and float to a dictionary on each node storing the data for connecting nodes. The Djkstra algorithm will cycle through the dictionary of the target starting node and saves the current path into a new dictionary. The algorithm moves onto the shortest path node and repeats the process until it finds the target end point. The Greedy algorithm instead calculates the distances between the next node in the current nodes dictionary and target end point, favouring the node with the shortest distance.
Constraints
To add some complexity to the pathfinding, I added some contraints to the nodes, forcing the pathfinding algorithms to seach for alternative routes. The contraint options avalible are blackholes, wormholes and fuel. The fuel contraint limits the number of jumps or distance the user's "ship" can travel and must reroute to a refuel node or "star" to be able to reach further distances. The blackhole contraint can block and destroy nearby routes to the blackhole randomly generated having the path avoiding those areas. The wormholes contraint teleports the user to another random wormhole point which will cause randomness to the path and unpridictibility.
